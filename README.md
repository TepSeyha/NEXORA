# NEXORA 4D

**Reality Is Only The Beginning.**

An immersive 4D-style web experience exploring the solar system and Earth with real-time 3D graphics.

![NEXORA](https://img.shields.io/badge/NEXORA-4D-53F3FF?style=for-the-badge)

## 🌟 Features

- 🌍 **Interactive 3D Earth** with real country borders and city lights
- 🪐 **Solar System Explorer** with all 8 planets
- ☀️ **Realistic Sun** with animated plasma and corona
- 🌙 **Moons** for major planets
- 💍 **Saturn and Uranus rings**
- ☄️ **Asteroid belt** between Mars and Jupiter
- 🎨 **Procedural shaders** for planet surfaces
- 🎯 **Click to focus** on any planet or country
- 📱 **Responsive** design for desktop and mobile

## 🛠️ Tech Stack

- **React 18** with Vite
- **Three.js** + **@react-three/fiber**
- **@react-three/drei** for controls and helpers
- **Custom GLSL shaders** for planet surfaces
- **GeoJSON** for country borders

```bash
